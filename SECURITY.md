# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities to the repository maintainers through GitHub's security advisory feature or by creating a private security advisory.

We take all security reports seriously and will respond within 48 hours.

## Security Considerations

This tool is read-only and does not modify any files. It only scans and reports issues found in text files.
